עוגה באהבה — פרויקט HTML + CSS
================================

פתחי את index.html בדפדפן או פתחי את כל התיקייה ב־Visual Studio Code.

מבנה הפרויקט:
- index.html — דף הבית.
- pages — אודות, עוגות, קינוחים, מתכון, הזמנה, אישור הזמנה ויצירת קשר.
- css/style.css — קובץ העיצוב החיצוני המשותף לכל הדפים.
- assets/images — התמונות המקומיות הקיימות בפרויקט.
- assets/media — סרטון MP4 וקובץ שמע WAV מקומיים.
- assets/files — קטלוג PDF.
- favicon.ico — אייקון האתר.
- נספחים-ספר-פרויקט.html — מפת חשיבה, תכנון מסכים והסברים להגשה.
- מדריך להסבר הקוד לספר פרויקט.txt — מדריך קריאה והסבר של מבנה הקוד.

תוכן המוצרים:
- בדף הבית מוצגים עכשיו 5 כרטיסי טעימה.
- בדף העוגות נשמרו 6 סוגי עוגות.
- בדף הקינוחים נשמרו 3 סוגי קינוחים.

למידה עצמית שהודגמה בפרויקט:
- CSS Variables.
- CSS Grid.
- פסאודו־אלמנטים, transform, filter ו־object-fit.
- תגית audio וקובץ שמע מקומי.
- קישורי tel, mailto והורדת PDF.

תמונות: השתמשנו בקובצי התמונה הקיימים בפרויקט, חתכנו רצועות טקסט/ממשק שנכנסו בטעות לחלק מהתמונות, ביצענו חידוד עדין ושמרנו אותן ברזולוציה המקורית. לא הגדלנו תמונות קטנות באמצעות מתיחה, כי הגדלה כזו מדגישה טשטוש ואינה משחזרת פרטים שאינם קיימים במקור.

בדיקות לפני הגשה:
1. לפתוח את index.html ולבדוק את תפריט הניווט ואת כל הדפים.
2. לבדוק את טופס ההזמנה ואת המעבר לדף thanks.html.
3. להפעיל את הסרטון ואת קובץ השמע המקומיים.
4. לבדוק את קישור הטלפון, קישור הדוא״ל ואת הורדת הקטלוג.
5. לבדוק תצוגה במסך מחשב ובמסך צר.
6. לצלם מסכי אמת של האתר הפועל לצורך ספר הפרויקט.

הערה: טופס ההזמנה מדמה שליחה לדף אישור ואינו מחובר לשרת אמיתי. פרטי הטלפון והדוא״ל שבדוגמה הם פרטי המחשה ויש להחליפם בפרטים אמיתיים רק אם נדרש ומאושר.

עדכון תצוגת תמונות:
קובצי התמונות שבתיקיית assets/images הוחלפו בעותקי המקור ברזולוציה גבוהה יותר
שהיו בפרויקט. קובצי CSS האחרונים מתאימים את גודל התמונה לרוחב המסך:
במחשב מוצגות גלריות בכמה עמודות, בטאבלט בשתי/שלוש עמודות ובנייד בעמודה אחת.
התמונות מוצגות בתוך הכרטיסים בעזרת object-fit, תוך שמירה על יחס תצוגה עקבי.
