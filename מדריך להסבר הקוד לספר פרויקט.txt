מדריך להסבר הקוד — עוגה באהבה
================================

1. מבנה HTML
- <!DOCTYPE html> מצהיר שהמסמך משתמש ב־HTML5.
- <html lang="he" dir="rtl"> מגדיר שפת עברית וכיוון כתיבה מימין לשמאל.
- <head> מכיל הגדרות וקישורים לקובצי עיצוב ואייקון.
- <body> מכיל את התוכן המוצג לגולש.
- <header> מכיל את אזור הכותרת והלוגו.
- <nav> מכיל קישורי ניווט.
- <main> מכיל את התוכן המרכזי של העמוד.
- <section> מחלק את התוכן לאזורים.
- <article> משמש לכרטיס מוצר עצמאי.
- <footer> מכיל זכויות יוצרים וקישורים נוספים.

2. קישורים ומדיה
- <a href="..."> יוצר קישור.
- tel: יוצר קישור לחיוג.
- mailto: פותח הודעת דוא״ל.
- download מציע להוריד קובץ.
- <img> מציג תמונה; alt הוא תיאור טקסטואלי חלופי.
- <video controls> מציג נגן וידאו.
- <audio controls> מציג נגן שמע עם כפתורי הפעלה.

3. טופס
- <form> עוטפת את שדות הטופס.
- <label> נותנת שם ברור לשדה.
- input type="text" / "tel" / "email" / "date" / "number" מאפשרים סוגי קלט שונים.
- required מחייב מילוי; minlength ו־pattern בודקים תקינות בסיסית.
- <select> מציג רשימת בחירה.
- <textarea> מאפשר לכתוב הערות.
- type="submit" שולח לדף האישור; type="reset" מאפס את הטופס.

4. CSS ו־Flex
- display:flex מפעיל פריסת Flex.
- justify-content מפזר פריטים לאורך הציר הראשי; משמש בכותרת ובפס היתרונות.
- align-items מיישר פריטים בציר המשני; משמש בכותרת ובכרטיסים.
- flex-wrap מאפשר ירידת פריטים לשורה נוספת; משמש בתפריט ובשורת התגיות.
- gap יוצר מרווח אחיד בין הפריטים.
- flex: 1 1 0 מאפשר לפריטים לגדול ולהתכווץ.

5. נושאי למידה עצמית
- CSS Variables: משתנים המוגדרים ב־:root ונקראים בעזרת var(). משמשים לצבעי המותג.
- CSS Grid: פריסה בשורות ובעמודות; משמשת בגלריית המוצרים ובטופס.
- פסאודו־אלמנטים ::before ו־::after מוסיפים קישוטים ללא תגית HTML נוספת.
- transform יוצר תנועה/שינוי גודל; filter משנה מאפייני תצוגה של תמונה.
- object-fit שומר על אופן התאמת התמונה למסגרת.
- Media Query משנה את הפריסה במסכים ברוחב שונה.
- audio מוסיף נגן שמע מקומי בדף אודות.

6. מבנה התיקיות
index.html הוא דף הכניסה; pages מכילה את שאר הדפים; css מכילה את העיצוב; assets/images מכילה תמונות; assets/media מכילה וידאו ושמע; assets/files מכילה PDF.

הטופס הוא הדמיה לימודית ואינו מחובר לשרת אמיתי.
